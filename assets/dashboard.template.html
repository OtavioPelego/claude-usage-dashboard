Fonte: os transcripts locais do Claude Code (~/.claude/projects), lidos pelo script da skill claude-usage-dashboard. O Claude Code só guarda o que rodou neste computador — o claude.ai e outros aparelhos não aparecem aqui. Os dados ficam no seu disco; esta página não envia nada para lugar nenhum. Contagem Claude Code (a padrão): entrada + saída de cada linha do transcript, sem cache (cada resposta do Claude aparece em várias linhas, e todas contam). É uma reconstrução da contagem do painel de uso do Claude Code: num teste de 89 dias de um único usuário o total ficou a cerca de 2% do painel (0,98×); dia a dia os valores podem variar mais — trate como estimativa, não como cópia garantida. Cache criado e cache lido (a conversa relida a cada resposta) aparecem só como secundárias. O Claude Code apaga transcripts antigos depois de um tempo, então o histórico começa no que ainda existia na primeira vez que o script rodou; rodar de novo de vez em quando mantém os dias já registrados.
Fascínio por dados — por que esta skill existe

Esta skill existe por causa de um fascínio meu por números. Eu me viciei em monitorar quanto gastava de tokens por dia e me incomodava quando não “torrava” o que tinha me proposto. Virou um jogo comigo mesmo: me empurrava a sentar e usar o Claude Code todo dia, aprender, me superar — e, por consequência, criar coisas que eu não teria criado sem esse empurrão.

Sei que o que importa de verdade é o que se constrói — coisas incríveis, úteis, necessárias —, não a quantidade de tokens.

Gastar token não é mérito por si só: para mim é um termômetro que me mantém em movimento.

Acredito de verdade que, sem este meu “vício” — junto com a convicção de que construir coisas realmente úteis (para mim e para os outros) é o objetivo maior —, eu provavelmente teria largado a ferramenta, e esta skill nem existiria.

Cada pessoa tem o seu objetivo. Tem quem queira o contrário: economizar, ficar dentro de um limite. Por isso o painel deixa escolher entre “atingir uma meta” e “ficar dentro de um limite” — a conta é a mesma, muda só a frase. Use do jeito que te ajudar. — Otávio
